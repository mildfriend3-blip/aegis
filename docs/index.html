What it is

An LLM agent that can call tools turns a prompt injection from a party trick into a remote-execution class bug for natural language. A payload hidden in a document the agent is asked to summarise can redirect its email, HTTP or SQL calls.

AEGIS scores 17 attacks across 9 categories against a tool-using agent, and reports two numbers for every defence: the attack success rate it leaves, and the legitimate-task utility it preserves. An undefended agent falls to every attack; a four-layer stack drives that to zero with no loss of utility.

Run it

Offline, no server, no API key — one command regenerates every number.

$ git clone https://github.com/mildfriend3-blip/aegis $ cd aegis $ pip install -e ".[dev]" $ aegis run $ pytest -q
